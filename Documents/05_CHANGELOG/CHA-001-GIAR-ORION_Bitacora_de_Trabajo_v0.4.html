Propósito y reglas

Esta bitácora registra lo que realmente se hizo: decisiones, tareas, archivos, pruebas, resultados y próximos pasos. No registrar planes como si fueran tareas terminadas.

Cada entrada futura debe incluir ID, fecha, módulo, objetivo, pasos realizados, decisiones, archivos afectados, pruebas, resultados/evidencias, problemas, estado y próximo paso.

Estados sugeridos: PLANNED, IN_PROGRESS, COMPLETED, TESTING, BLOCKED, APPROVED, REJECTED.

La aprobación conceptual de un módulo no significa implementación. Si no hubo código o pruebas, registrar «No aplica: etapa de diseño».
